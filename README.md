# ProjectionAI downloads

Installers for ProjectionAI, projection mapping for any object.

Download the latest Windows installer from
[Releases](https://github.com/sashtriyasam/projectionai-releases/releases/latest).
Once installed, ProjectionAI tells you when a new version is out and can
install it for you.
